Auteur : Lokinas Peter Lemire

Date : Spetembre 2020-Mars 2021

Description : Ce projet cherchait à nous apprendre à utiliser StarUML pour developer des solution logiciels. On a donc dévellopé, par étapes:
1. des cas d'utilisation, des diagrammes de séquences de système, des modèles de domaines
2. des diagrammes d'interaction, des diagrammes de classes de conception
3.  des diagrammes d'implémentation, du code généré grâce aux diagrammes créés.
